Full Dataset (`data`)

How It Works

1. The code picks 4 random starting positions from the dataset.

2. From each position, it grabs a chunk of 8 characters for the input (x).

3. It also grabs the next chunk (shifted by one) for the target (y).

4. This creates a "batch" of examples for the model to learn from. Press the button to see it happen!
