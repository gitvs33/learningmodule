Click on a word to see how it "attends" to other words in the sentence. Higher attention scores mean the words are more relevant to the selected word's context.

How It Works: The 3-Step Logic

1. Find Relevance (Q & K) 🔑

The model generates a Query vector for the selected word and a Key vector for every word. It compares the Query to each Key to get a raw relevance score.

2. Calculate Weights (Softmax) ⚖️

These raw scores are fed into a softmax function, which converts them into percentages (attention weights). This decides how much focus to place on each word.

3. Blend Information (V) 🍹

Finally, the model creates a new, context-rich output by summing up the Value vectors of all words, weighted by their attention scores.
