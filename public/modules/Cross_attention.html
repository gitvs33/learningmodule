Cross-Attention: The Decoder's Superpower

This is the bridge between the Encoder and Decoder. It allows the Decoder to "look up" relevant information from the original input sentence.

The Logic: Q, K, V

Cross-Attention uses the same Query, Key, Value logic as self-attention, but the sources are different:

  • Q
    Query (from Decoder): This is the Decoder's question. It's a vector representing its current state (e.g., "I've just written 'Die Katze', what do I need next?").
  • K
    Key (from Encoder): This is the "label" on each piece of information in the Encoder's memory. The Decoder compares its Query to these Keys to find the best match.
  • V
    Value (from Encoder): This is the actual content or meaning of the information. Once the best Key is found, the Decoder takes its corresponding Value.

When Is It Used?

Cross-Attention is essential in any task where one sequence needs to be generated based on another.

  • Machine Translation: The target language (Decoder) looks at the source language (Encoder).
  • Question Answering: The answer (Decoder) looks at the context/document (Encoder).
  • Text Summarization: The summary (Decoder) looks at the full article (Encoder).
